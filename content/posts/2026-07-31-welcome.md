If you are reading this, you have successfully double-clicked a file in a
fake operating system. The muscle memory never left.

This site is my homepage, rebuilt as the kind of machine I grew up in front
of — teal desktop, chunky window chrome, a startup chord. Everything on it
is real in the way fake things can be: the windows drag, the Task Manager
ends tasks, and killing `explorer.exe` has the consequence you would
expect.

Under the hood it is a fully static Next.js site. Every window's content —
including this post — is a Markdown file in the repository, which is open
source at
[zzxzzk115/portfolio-98](https://github.com/zzxzzk115/portfolio-98).

More posts will appear here. Probably about rendering. It is always about
rendering.
