If you are reading this, you have successfully double-clicked a file in a
fake operating system. Congratulations — the muscle memory never left.

## Why a Windows 98 homepage?

My "serious" academic homepage lives at
[zzxzzk115.github.io](https://zzxzzk115.github.io), and it does its job:
publications, CV, research interests, all in tasteful academic beige. But a
personal homepage should also be *personal*. I grew up in front of machines
that looked like this — teal desktop, chunky window chrome, that startup
chord — and I build game engines and renderers for a living, so building a
tiny operating system for the browser is roughly my definition of a good
weekend.

Everything here is real, in the sense that fake things are real when they
work: the windows drag, the Task Manager ends tasks, killing `explorer.exe`
has the consequence you'd expect, and the wallpapers marked ★ are live GLSL
shaders rendering as you read this.

## How it's built

Next.js, static export, no backend. Content — including this very post —
is Markdown in a `content/` folder. The site is open source at
[zzxzzk115/portfolio-98](https://github.com/zzxzzk115/portfolio-98); when
it stabilizes I plan to split off a template so you can have a `*-98` of
your own.

More posts will appear in this folder. Probably about rendering. It's
always about rendering.
